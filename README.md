# Страховая платформа для бизнеса

[Открыть веб-справочник](https://aleksandrermolov87-cloud.github.io/insurance-platform-handbook/)

Справочник проекта объединяет материалы об архитектуре страхования ЮЛ/ИП, функциональных модулях, рабочем месте менеджера SFA и интернет-банке НИБ. Срез подготовлен 27 ноября 2026 года.

## Материалы

- Архитектурное описание и пять реестров интеграций. В трёх каталогах 109 системных и компонентных записей, 220 строк операций, 60 записей о данных, продуктах, процессах и документах. Для каждой позиции указан источник.
- 3D-карта в двух масштабах. В обзоре 42 объекта и 65 действий. Подробный режим включает 389 записей и 901 связь. Для всех 901 связей сохранены исходные пары узлов, направление и тип отношения. У каждой системы есть карточка с её соседями и переходом в 3D-карту.
- 21 интерактивная визуализация в 8 архитектурных главах и 13 описаниях модулей. На схемах можно выбрать узел, прочитать пояснение и проследить его связи. В паспорте модели показан состав трёх каталогов.
- В каталогах доступны дерево систем, матрица 220 операций по этапам и статусам, 12 схем взаимодействий и карта девяти бизнес-процессов. Карточка каждого процесса раскрывает шаги и участников.
- 13 тематических материалов Пространства и отдельный навигатор по 42 предметным страницам. В материалах различаются архитектурное описание, целевое требование, результат исследования и решения владельца продукта.
- Атлас экранов SFA и НИБ. В указателе 199 фреймов. Все 199 изображений можно рассматривать и листать непосредственно на сайте, у каждого есть описание. С кликабельных шагов схем можно перейти в подходящий экран или состояние SFA и НИБ и вернуться к выбранному шагу. Каждая запись содержит ссылку на конкретный узел Figma. Проверены группа страницы, карточки дизайн-чека и локальные исключения. Четыре исключённые секции SFA не опубликованы.
- Комплексная защита бизнеса. На одной схеме показаны девять шагов оформления в НИБ и SFA. У каждого шага и его вариантов есть ссылка на соответствующее состояние работающего прототипа и на конкретный пункт требований с возвратом к схеме. Доступны 69 состояний, включая четыре только для SFA. Полный текст и таблицы 67 страниц требований v1.5 можно скачать из карточки продукта. Изменения проверки адреса от 26 ноября и особенности демонстратора отмечены отдельно. [Открыть схему](https://aleksandrermolov87-cloud.github.io/insurance-platform-handbook/#/product)

## Сборка

Интерфейс использует React и `@alfalab/core-components` с корпоративной темой. Статические данные находятся в `src/data`. Для установки и сборки выполните `npm ci` и `npm run build`. Для локального просмотра используйте `npm run dev`. GitHub Pages публикует каталог `docs` из ветки `main`. Пути разделов после `#/` работают при прямом открытии ссылки.
