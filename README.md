# Страховая платформа для бизнеса

[Открыть веб-справочник](https://aleksandrermolov87-cloud.github.io/insurance-platform-handbook/)

Справочник проекта объединяет материалы об архитектуре страхования ЮЛ/ИП, функциональных модулях, рабочем месте менеджера SFA и интернет-банке НИБ. Срез подготовлен 27 ноября 2026 года.

## Материалы

- Архитектурное описание и пять реестров интеграций. В трёх каталогах 109 системных и компонентных записей, 220 строк операций, 60 записей о данных, продуктах, процессах и документах. Для каждой позиции указан источник.
- 3D-карта в двух масштабах. В обзоре 42 объекта и 65 действий. Подробный режим включает 389 записей и 901 связь. 417 связей сохраняют исходную предметную роль и направление. Для 484 указана обобщённая связь с функциональной областью или документом.
- 13 тематических материалов Пространства и отдельный навигатор по 42 предметным страницам. В материалах различаются архитектурное описание, целевое требование, результат исследования и решения владельца продукта.
- Атлас экранов SFA и НИБ. В указателе 199 фреймов. Для 135 размещены изображения, 79 экранов снабжены описаниями. Каждая запись содержит ссылку на конкретный узел Figma. Проверены группа страницы, карточки дизайн-чека и локальные исключения. Четыре исключённые секции SFA не опубликованы.
- Комплексная защита бизнеса. Действующий прототип, полный текст и таблицы 67 страниц требований v1.5, отдельная заметка об изменении прототипа от 26 ноября. Скачать текстовую версию можно из карточки продукта.

## Сборка

Интерфейс использует React и `@alfalab/core-components` с корпоративной темой. Статические данные находятся в `src/data`. Для установки и сборки выполните `npm ci` и `npm run build`. Для локального просмотра используйте `npm run dev`. GitHub Pages публикует каталог `docs` из ветки `main`. Пути разделов после `#/` работают при прямом открытии ссылки.
